# Views

This folder is reserved for BoveCloset view-layer files.

Current prototype files remain in the existing top-level `index.html`, `src/app.js`,
and `src/styles.css`. Future screens can be split here into modules such as:

- `WardrobeGallery`
- `OutfitGenerator`
- `StylistChat`
- `UserProfile`
- `CommunityFeed`
